# Use Arcade Shelf with other apps

Shelf uses Arcade Link to receive content, open an explicit picker and offer compatible actions for selected items. A peer appears when it is installed and publishes a usable action. Manage the master connection and per-app toggles in **Settings → Connected apps**.

## Arcade Box

Run a compatible Box transformation or saved pipeline on selected Shelf content. Box owns the operation; Shelf can collect returned temporary files so you can open or hand them off again.

## Arcade Clipboard

Open Clipboard's explicit picker or use a compatible action to send eligible content to your devices. Clipboard owns device selection and privacy rules. Shelf does not maintain clipboard history.

## Arcade Find

Use Find's **Add to Shelf** action to collect search results as file references. From an item, **Search in Find** opens Find for that file; **Find matching files** is available for text items.

## Arcade Lens

Run a compatible Lens capture, image recognition or analysis action on selected content. Lens owns the capture and analysis; Shelf can retain supported returned images or outputs.

## Arcade Look

Use a compatible **Preview** or **Inspect** action on selected files. You can also press **Space** on a compatible selection. Look owns the preview and inspection. Its URL preview offer is limited to file URLs; ordinary web links open in the browser.

## Arcade Wheel

Use a compatible Shelf action from a Wheel slot. Wheel can open Shelf or refer to a named collection; the selected item remains managed by Shelf.

## Arcade Tools

Tools can install, update or remove Shelf from its **Apps** tab. When Tools is running, it can host Shelf's tray controls inside the shared Arcade tray icon; Shelf keeps its own tray icon when Tools is closed.
