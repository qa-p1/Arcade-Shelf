## Show Shelf

| Action | Linux | Windows | macOS |
| --- | --- | --- | --- |
| Show or toggle Arcade Shelf | Ctrl+Alt+S | Ctrl+Alt+S | ⌃⌥S |

## Collection and items

| Action | Linux | Windows | macOS |
| --- | --- | --- | --- |
| Select all visible items | Ctrl+A | Ctrl+A | ⌘A |
| Copy selected content | Ctrl+C | Ctrl+C | ⌘C |
| Collect supported clipboard content | Ctrl+V | Ctrl+V | ⌘V |
| Undo the last addition | Ctrl+Z | Ctrl+Z | ⌘Z |
| Focus the collection filter | Ctrl+F | Ctrl+F | ⌘F |
| Remove selected items from this collection | Delete<br>Backspace | Delete<br>Backspace | ⌦<br>⌫ |
| Open the focused item or confirm a picker selection | Enter<br>NumpadEnter | Enter<br>NumpadEnter | ↩<br>NumpadEnter |
| Preview the selection through Look when available | Space | Space | Space |
| Cancel a picker, clear the filter or close the panel | Escape | Escape | ⎋ |
| Move the focus left; Shift selects a range, Ctrl toggles | ←<br>Shift+←<br>Ctrl+← | ←<br>Shift+←<br>Ctrl+← | ←<br>⇧←<br>⌃← |
| Move the focus right; Shift selects a range, Ctrl toggles | →<br>Shift+→<br>Ctrl+→ | →<br>Shift+→<br>Ctrl+→ | →<br>⇧→<br>⌃→ |
| Move the focus up; Shift selects a range, Ctrl toggles | ↑<br>Shift+↑<br>Ctrl+↑ | ↑<br>Shift+↑<br>Ctrl+↑ | ↑<br>⇧↑<br>⌃↑ |
| Move the focus down; Shift selects a range, Ctrl toggles | ↓<br>Shift+↓<br>Ctrl+↓ | ↓<br>Shift+↓<br>Ctrl+↓ | ↓<br>⇧↓<br>⌃↓ |
