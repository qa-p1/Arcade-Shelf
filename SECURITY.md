# Security policy

## Reporting

Report a vulnerability privately through GitHub's "Report a vulnerability" (Security tab of this repository), not in
a public issue. Expect an answer within a week. Fixes ship as a patch release through the normal rc → promote path. A
release found to be unsafe after it shipped gets the catalog's `bad` flag: Arcade Tools stops offering it and tells
installed copies to roll back.

## What Arcade Shelf guards, and how

Shelf keeps what you drop, paste or send to it: **references** to files and folders (an absolute path, never a copy),
links, text and rich text, and images you drop or paste, which it copies. Its collections, preferences and copies live in
Shelf's own data folder under your user account (`~/.local/share/arcade/shelf` unless `ARCADE_SHELF_HOME` is set; see
`dataRoot()` in `src/link/Service.cpp`): a SQLite database and an `objects/` folder. For a referenced file Shelf reads
its name, size and kind, and decodes it only to draw a thumbnail when it is an image; it reads or copies a file's content only
when another Arcade app hands it a file or text to keep, or when you drop or paste text or an image (below). Shelf
has no network code: no `QNetworkAccessManager`, TCP, UDP, TLS, HTTP or WebSocket class is used anywhere in `src/`, `ui/` or
the vendored Arcade Link. `Qt6::Network` is linked (`CMakeLists.txt`) only because Link's local sockets
(`QLocalServer`, `QLocalSocket`) live in that Qt module. Shelf has no content search, no screen capture and no web view, so
those rows of other Arcade apps' policies do not apply.

## Dependencies

Shelf has no package-manager dependencies except GitHub Actions. A pull request that adds or bumps one with a known
advisory fails `actions/dependency-review-action`, and Dependabot proposes weekly, grouped updates for them
(`.github/workflows/ci.yml`, job `dependency-review`; `.github/dependabot.yml`). The `jurplel/install-qt-action` is pinned
to a commit; the other actions are referenced by major-version tag, and Link's reusable release workflows by the tag
`v1.0.13`. Qt is pinned in `.github/workflows/ci.yml` to **6.8.3** (with the `qtimageformats` module) and installed by the
`jurplel/install-qt-action`; Dependabot does not update it, it is changed by hand. Arcade Link is vendored at a pinned tag,
`v1.0.13` (commit `a24146fd87ff77ed362f518a414eaf266512f839`), with the SHA-256 of every vendored file recorded in
`vendor/arcade-link/VENDORED.json` and `vendor/arcade-link/shared-provenance.json` (`VENDORED.md`); `scripts/check-vendor.py`
re-checks those hashes, offline, and CI runs it through `scripts/check.py`.

The Linux AppImage bundles system libraries from the build host (the CI `package` job runs on `ubuntu-22.04`).
`scripts/package-linux.py` runs `ldd` on the program and on every bundled plugin and copies each shared library it resolves
into `lib/`, except those that match its `BASE_LIBS` list, which stay OS-supplied: the C library family, `libstdc++`,
`libgcc_s`, OpenGL, EGL, Vulkan, `gbm` and `drm`, `fontconfig`, `freetype`, `harfbuzz`, `expat`, `zlib`, `libuuid`,
`libdbus-1`, `libasound`, `libxkbcommon`, `libwayland-*`, and the X11 and XCB client libraries. It also copies Qt's
`platforms`, Wayland, `imageformats`, `iconengines`, `platformthemes`, `xcbglintegrations`, `egldeviceintegrations`
plugin folders, only the SQLite SQL driver, and the `QtQml`, `QtQuick` and `Qt5Compat` QML modules, and sets an rpath of
`$ORIGIN:$ORIGIN/../lib`. It records each copied library's path and SHA-256 in
`share/arcade-shelf/licenses/runtime-inventory.json` and keeps the distribution's copyright files when `dpkg-query` is
available. The only download it makes is `appimagetool` 1.9.0 (x86_64), checked against a pinned SHA-256. Bundled libraries
are not updated by your distribution: a fix for one of them reaches users only in a new Shelf release. Third-party licences
are in `THIRD_PARTY_NOTICES.md`. No security audit or advisory scan of the bundled libraries is part of these workflows.
